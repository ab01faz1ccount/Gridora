# apps/web — web application

React + TypeScript interface, Persian-first and right-to-left: sign-in, workspaces, upload with compatibility report, a virtualized grid for 100,000+ rows, cell editing, copy/paste, undo/redo and a history panel.

Full description of what it does, how it is built and its limits: [docs/REFERENCE.md](../../docs/REFERENCE.md#web-app-appsweb). Design record: [DESIGN.md](../DESIGN.md)

```bash
npm ci
npm run dev     # http://localhost:5173, proxies /api to http://localhost:8000
npm run check
```
